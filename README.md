💪 Home Workout

Your weekly workout planner. Stay consistent, one day at a time.

📌 About the Project
Home Workout is a mobile application developed using Flutter and Dart, designed to help individuals maintain a consistent exercise routine without going to the gym.

The application provides a structured Monday-to-Sunday home workout schedule where users can view their assigned daily exercises, mark completed activities using interactive checklists, and monitor their weekly workout progress.

Its main goal is to make exercising more organized, accessible, and manageable, especially for beginners who prefer working out at home.

✨ Features
Weekly Workout Schedule – Organized workout routines from Monday to Sunday.
Daily Workout Checklist – Interactive checkboxes for tracking completed exercises.
Exercise Instructions – Displays exercise names, sets, repetitions, and durations.
Daily Progress Tracking – Monitors completed exercises throughout the day.
Weekly Progress Tracking – Provides an overview of workout completion.
Local Progress Storage – Saves workout progress directly on the user's device.
Offline Accessibility – Access workout routines without requiring an internet connection.
Daily Motivation – Encouraging messages to help users stay consistent.

🛠️ Technologies Used
Flutter
Dart
SharedPreferences
Visual Studio Code

🎯 Project Objectives
Encourage consistency in exercising.
Provide structured home workout routines.
Help beginners establish healthy exercise habits.
Make workout tracking simple and convenient.

📱 Target Users
Individuals who want to exercise at home, especially beginners, students, and people with limited access to gym facilities.
